# 🍽️ Bengaluru Restaurant Data Analysis

## 📌 Project Overview

The **Bengaluru Restaurant Data Analysis** project focuses on exploring and analyzing restaurant data from Bengaluru, India, to uncover meaningful insights into restaurant ratings, cuisines, customer reviews, and geographical distribution.

The project involves data cleaning, data preprocessing, and interactive dashboard development using Microsoft Excel. The cleaned dataset is used to analyze restaurant characteristics and present key insights through visualizations and interactive filters.

This project demonstrates how raw restaurant data can be transformed into structured information to support data-driven decision-making and improve understanding of Bengaluru's restaurant landscape.

## 🎯 Project Objectives

- **Data Cleaning:** Identify and handle missing values, inconsistent formats, invalid records, and potential duplicates.
- **Restaurant Analysis:** Explore restaurant ratings, review counts, and other restaurant attributes.
- **Cuisine Analysis:** Understand the distribution and variety of cuisines offered by restaurants.
- **Location Analysis:** Analyze restaurant distribution across different pincodes and geographical locations.
- **Customer Review Analysis:** Examine customer review counts to understand engagement across restaurant listings.
- **Interactive Dashboard Development:** Build Excel dashboards with filters and visualizations for exploring restaurant data.
- **Data-Driven Insights:** Convert raw data into meaningful insights through analysis and visualization.
- **Portfolio Development:** Demonstrate practical data analytics skills through a real-world dataset.
